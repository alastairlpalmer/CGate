{% comment %} The preview pane of a list split view: a column beside the list from `lg`, a bottom sheet below it (static/js/split_view.js, and the "List split view" block in static/css/input.css). Context: pane_id — the pane's id, the same as data-split-pane on the split view. The body, the counter, the arrows and "Open full page" are named after it, which is how the script finds them. noun — what one row is ("owner", "invoice"), for the labels. The chrome stays put across swaps — only the body is replaced when another row is picked — so the counter and the arrows never flicker. hx-select and hx-push-url sit on the pane, not on a trigger: split_view.js names this element as the request's source, and htmx reads both off it. Without that the request inherits the boosted body's hx-push-url="true" and the address bar becomes the preview URL — which then breaks the Back button and the pop-up sheet's in-place refresh, since that refetches whatever the address bar says. {% endcomment %}
{% comment %}Desktop only: drag to give the list or the pane more room. panel_resize.js remembers the width per page in localStorage.{% endcomment %}
