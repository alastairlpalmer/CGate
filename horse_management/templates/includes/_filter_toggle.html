{% comment %} The filter toggle for a list page. On a phone it is teleported into the app bar, so it lands beside the search box instead of costing the list a row of its own. On a computer there is no app bar, so a labelled "Filters" button is teleported into the page's own [data-filter-slot], which each list page puts in a row it already has (beside Select, the period or the search box). Render it inside an element running the `listFilters` Alpine component (base.html), whose panel it opens. base.html empties #app-bar-slot before each boosted swap, so the button never outlives its page. The badge counts controls marked [data-filter-field] inside that element. {% endcomment %}
