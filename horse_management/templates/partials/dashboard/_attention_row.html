{% load ui_extras %} {% comment %} One inbox row (core.dashboard.attention.Row): a horse, a shared visit, or a loose item such as an invoice. One line per thing to do — what it is, how late, the button — so the list scans like a checklist. The list is a CSS container (.attn-list, static/css/input.css) and the row lays itself out by the width it has, whatever the viewport: from 34rem it is one line (the name, what is due, how late, the button; where the horse is and the exact date join in from 48rem), narrower than that the badge and the buttons take a line of their own under the text. A horse with two things due gets one line per thing under one name. Colour says how urgent: the left edge and the icon are red when overdue, saddle when due today, sage otherwise. Whether the row shows is the list's call (`shown`, static/js/dashboard.js): it must pass the page's filter chip and be among the first four that do, unless the list is expanded. {% endcomment %}
