{% comment %} The Near you card (plan 6.7). Context: near_you_card from core.views.dashboard.near_you_card, near_you_maps ({site: payload}) and the dashboard's `visible` set. One slot, one card, never two: the Alpine component `nearYouCard` (static/js/location_map.js) picks the site (GPS → the dashboard's chosen site → the only site → hide) and the highlighted location (GPS → pinned → last opened → none), then aims the compact map for that site. One compact map is rendered per site and only the chosen one is shown, so no fetch is needed when GPS picks another. The root is the dashboard grid item itself, so a card that hides (no site to show) takes no room. It is the first zone: on a phone the map is square at the top; on a wide screen the card takes the left half (seven columns of twelve from 1728px), Needs action the rest, and the map fills the card's height (static/css/input.css, .location-map.is-compact). The grid in dashboard.html listens for `near-you:visible` and gives Needs action the full width whenever the card cannot show. Two tap targets (plan 2.5): a badge opens that location's horse list; everywhere else on the card opens the Map tab. With a fine pointer the map itself is for looking — drag, Ctrl (⌘) + scroll, +/- — and the header, footer and the Full map button open the Map tab. {% endcomment %} {{ near_you_card|json_script:"near-you-card-data" }}
