{% comment %} The Near you card (plan 6.7). Context: near_you_card from core.views.dashboard.near_you_card, near_you_maps ({site: payload}) and the dashboard's `visible` set. One slot, one card, never two: the Alpine component `nearYouCard` (static/js/location_map.js) picks the site (GPS → the dashboard's chosen site → the only site → hide) and the highlighted location (GPS → pinned → last opened → none), then aims the compact map for that site. One compact map is rendered per site and only the chosen one is shown, so no fetch is needed when GPS picks another. The root is the dashboard grid item itself, so a card that hides (no site to show) takes no room. On a phone it comes first — it is the reason an operator out in the yard opens the app — and the map is square. On a wide screen it sits square beside Needs action and Next 14 days (five columns of twelve from lg, four from xl, so a landscape tablet still gets a map worth looking at); the grid in dashboard.html listens for `near-you:visible` to keep that column only while the card shows. Two tap targets (plan 2.5): a badge opens that location's horse list; everywhere else on the card opens the Map tab. {% endcomment %} {{ near_you_card|json_script:"near-you-card-data" }}
