{% comment %} The Near you card (plan 6.7). Context: near_you_card from core.views.dashboard.near_you_card, near_you_maps ({site: payload}) and the dashboard's `visible` set. One slot, one card, never two: the Alpine component `nearYouCard` (static/js/location_map.js) picks the site (GPS → the dashboard's chosen site → the only site → hide) and the highlighted location (GPS → pinned → last opened → none), then aims the compact map for that site. One compact map is rendered per site and only the chosen one is shown, so no fetch is needed when GPS picks another. The root is an item of the dashboard's left column, so a card that hides (no site to show) takes no room. It sits under the month calendar, two thirds of the width beside the Timeline on a wide screen; on a phone the map is square (static/css/input.css, .location-map.is-compact). Two tap targets (plan 2.5, revised 2026-09-07): a badge opens that location's page; everywhere else on the card opens the Map tab. With a fine pointer the map itself is for looking — drag, Ctrl (⌘) + scroll, +/- — and the header, footer and the Full map button open the Map tab. {% endcomment %} {{ near_you_card|json_script:"near-you-card-data" }}
{% comment %}The header holds the location chip and the site choice (partials/dashboard/site_tools.html; dashboard.html moves them in and out), so the map and the site it draws are chosen in one place. A GPS match is named by that chip, so the card's own label only shows for a pinned or last-opened location. The plain site name shows when it is not the chosen site (GPS found another, or there is one site and no choice to show).{% endcomment %}
