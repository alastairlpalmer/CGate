{% comment %} The one location map (plan 6.2). Used by the Map tab (variant 'full') and the Near you dashboard card (variant 'compact'); the same partial and the same Alpine component draw both, `variant` only changes interaction and density. Context: payload core.dashboard.board.map_locations(site) variant 'full' | 'compact' | 'phone' picks truthy when a tap should hand the location to the board beside the map instead of opening its page highlight optional location pk to light up (compact: crop around it) pinned optional pinned location pk (shows a pin marker on its badge) Rendering rule (plan 2.2), applied by static/js/location_map.js per location: if boundary → polygon; else if point → circle sized by capacity; else nothing. The badges are real links layered above the map — the capacity ring partial at 44 px, or the count / land-use badge exactly as the Yard board tile shows them — positioned by the script at the server-computed anchor. Badges whose anchors are closer than a badge is wide are pushed apart (static/js/map_layout.js) and a moved badge keeps a leader line, drawn in the SVG below, back to its anchor. Each location's name sits under its badge: on the full map whenever they fit, on the compact card for the highlighted location only. Tapping a badge or, on an interactive map, a shape opens that location — or, where `picks` is set, hands it to the board beside the map instead. A tap on the full map outside every shape opens the Locations list; on a picking map it puts the open location away. In the compact variant the card handles every tap that is not a badge. With a fine pointer both variants drag and zoom (see mount() in the script); Fit brings the whole site back, Map shows or hides a muted OpenStreetMap layer under the shapes (on by default on the Map tab, off on the card, the choice remembered per device), and the compact variant's Full map button opens the Map tab. {% endcomment %} {% with site_slug=payload.site|slugify %}{% with map_id="map-data-"|add:site_slug|add:"-"|add:variant %}
