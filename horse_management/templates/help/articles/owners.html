The Owners area keeps the contact details of the people who own the horses on your yard. Use it to see the horses, invoices and statement of each owner.

Find an owner

  1. Open Owners in the sidebar. On a phone, select More, then Owners.
  2. Read the list. It shows the Name, the Contact details and the number of Horses of each owner.
  3. Select the name of an owner to open the owner page.

Archived owners are not in the list. To see them, select the link to the archived owners below the list.

Add an owner

  1. Select the + button at the top right of the page.
  2. Select Add owner.
  3. Type the Name of the owner.
  4. Type the Email, the Phone number and the Address.
  5. Select Save.

You need full access to Owners to add or change an owner.

Change the contact details

  1. Open the owner page.
  2. Select Edit.
  3. Change the details. For example, type a Purchase order or reference for their invoices.
  4. To stop the vaccination, farrier and breeding emails, clear the Email health reminders check box.
  5. Select Save changes.

Select the One invoice per horse check box if the owner wants a separate invoice for each horse.

Read the owner page

  • Outstanding, Unbilled charges and Last payment show the money position of the owner.
  • Contact Information shows the email, phone and address.
  • Current Horses shows the horses on the yard now. Other Horses shows the horses that departed.
  • Unbilled Charges and Recent Invoices show the money that the owner must pay.

When the owner has a share of a horse, the share shows as a percentage next to the name of the horse. To change a share, open the horse. Then select Manage on the Ownership card.

Send a statement

  1. Open the owner page.
  2. Select Statement. The Statement of Account shows each invoice and the Balance.
  3. Select Download PDF to keep a copy.
  4. Select Email Statement to send the statement to the owner.

You need access to Invoices to see a statement. To email it, you need full access to Invoices, and the owner must have an email address.

Make an invoice for an owner

  1. Open the owner page.
  2. Select Create Invoice.
  3. Set the Period Start and the Period End.
  4. Read the Preview of the charges.
  5. Select Create Invoice.

Common problems

The owner page says "Emails to this address are not arriving". What do I do?
Check the email address with the owner and select Edit to correct it. If the address is correct and works now, select It works now.
I cannot archive an owner. Why?
The owner has horses on the yard, or a share in an active horse. Move or depart the horses, or change the ownership first.
I selected Statement or Create Invoice, and Cgate shows a message about my role. Why?
Your role does not give you access to Invoices. Ask an administrator to change your role.
The Create Invoice button is not on the owner page. Why?
The owner is archived. Select More, then Restore owner, to use the owner again.
