Training holds what each horse did and what is planned for it. Each record is one piece of work by one horse on one date: for example a canter, a session on the horse walker or a rest day. The lot board shows each day's lots and their horses.

The Overview

Select Training in the sidebar. On a phone, select Training on the bar at the bottom. The Overview opens. It shows:

  • Today's lots, how far each one is, and the horses that do not go out today.
  • Needs attention: lots that are not confirmed, horses with no work, fast work on days in a row, first work after a long gap, and horses behind on their exercise days.
  • This week: what each horse did on each day. In a large yard, each lot shows as one row. Select a lot to see its horses.
  • Not in work: horses on rest or box rest, and which ones need a decision.
  • Tomorrow's board, and who rides what today.

In a yard with more than 25 horses in work, use the lot buttons at the top to show one lot.

A new yard sees a list of set-up steps in place of the figures. The list goes when the yard has lots, horses in its lots, and a way to start the board.

Horses on rest: the review date

A horse on Resting or Box rest can have a Review on date: the date to check it again. Select Change next to the horse in Not in work, or on the horse page. On that date the horse shows in Needs attention and on the dashboard. When the horse goes back in work, the date is cleared.

The lot board

  1. On the Overview, select Open today's board, or select the Board tab.
  2. If the day has no board, choose how to start it: from the lots, a copy of the last board, or empty. Select Start the board.
  3. Use the arrows to go to another day. You can start tomorrow's board the evening before.

Each lot shows its work, its time and its horses in order. Change sets the lot's work for the day. A horse with its own work for the day keeps it, and shows it with a pencil mark. Select a horse's name to change its own work, minutes or notes.

Use the … button on a horse to move it to another lot for the day, or to take it off the board for the day. Add horse adds a horse to the lot for the day only. The lot on the Lots tab does not change.

Confirm a lot

Work on the board counts only when someone confirms it. When the lot comes back, select Mark lot done. Every planned horse becomes Done. A horse marked Did not work stays as it is.

If you confirmed by mistake, select Reopen lot. It changes back only what Mark lot done changed. Planned work from a past day shows as Not confirmed, and the board names the day.

Did not work

  1. On the horse's row, select Did not work.
  2. Select the reason, for example Lame or sore.

To undo it, select Undo on the row. For Lame or sore, the row has links to record a condition or a vet visit. To cancel a whole lot, for example for the weather, select Change on the lot, choose the reason and select Cancel lot.

Record training for one horse

  1. Open the horse's page.
  2. In the Record card, select Training.
  3. Select the work and the date.
  4. Select the status: Done, Planned or Did not work.
  5. Select Save.

A record for today or an earlier date starts as Done. A record for a later date starts as Planned. Work cannot be Done on a date after today.

If the horse did not work, select Did not work and give the reason, for example Lame or sore. If you leave Minutes empty, Cgate uses the usual minutes of the work.

You can also select Training activity in the Add menu.

Record training for many horses

  1. Select Horses in the sidebar.
  2. Tick the box next to each horse.
  3. In the bar at the bottom of the screen, open Choose action....
  4. Select Record Training.
  5. Select Apply to Selected.
  6. Complete the form, then select Record for and the number of horses.

Cgate makes one record for each horse. A horse that has left the yard is not recorded, and the message names it.

Confirm planned work

Planned work counts as work only when someone confirms it. Planned work from a past day shows as Not confirmed.

  1. Select Training in the sidebar. The Log tab opens.
  2. Select Show them in the yellow box, or set Status to Not confirmed.
  3. Tick the rows.
  4. Select Mark done. Or choose a reason and select Did not work.

On a horse's page, the Training card has the same two buttons on each planned row.

Training status

Each horse has a training status: In work, Light work, Pre-training, Resting, Box rest or Not in training. A horse that has never been in Training is Not in training.

  1. Open the horse's page.
  2. In the Training card, select Change.
  3. Select the status and the date it starts. You can also choose the horse's lot here.
  4. Select Save.

In work, Light work and Pre-training horses go on the lot board. If you put a horse on Box rest after the day's board started, tick Also change the lot boards: its planned work today becomes Did not work, and its later planned work is removed.

Lots

A lot is a group of horses that usually work together, for example 1st lot. A horse is in one lot at most.

  1. Select Training in the sidebar, then the Lots tab.
  2. Select Add lot. Give it a name, its usual work and its usual time.
  3. On the lot, select Add horses. Tick the horses, then select Add to and the lot's name.

Use Up and Down to set the order the horses go out. Use Move to to put a horse in another lot. A horse that is Not in training moves to In work when it joins a lot.

A horse that leaves the yard stays in its lot, under Left the yard, in case the departure is undone. To archive a lot, move or remove its horses first.

Week plan

The week plan gives each lot its usual work and venue for each day of the week, for example Tuesday: Fast work, Woodchip gallop, or No lot on Sunday.

  1. Select Training, then the Set up tab.
  2. In Week plan, select Edit week next to a lot.
  3. For each day, choose the work and the venue, or No lot. Usual uses the lot's usual work.
  4. Select Save.

To start each board from the week plan, set Lot board to From the week plan on the same tab.

Riders, gear and venues

Add riders and venues on the Set up tab. A rider can have a login: that rider sees their own horses at the top of the board. The owner is always a choice of rider, for an owner who rides their own horse.

On a horse's Training card, select Change to set its usual rider and gear. New work on the board takes them. A change on the board for one day does not change the usual rider.

On the board, use Rider to show only one rider's horses.

Workload facts and the 28-day strip

The horse's Training card and the board show short facts, for example No work for 4 days, Fast work 2 days running, First work in 16 days or 3 of 5 days this week. They state what the records say. They do not give advice.

If the days with no work hold planned work that nobody confirmed, the fact says 4 days not confirmed: the horse may have worked. Set the number of days for "No work" on the Set up tab. Set a horse's exercise days a week with Change on its Training card.

The strip shows the last 28 days, oldest on the left: E easy, S steady, F fast, R rest, × did not work, ? planned.

Print, TV and download

On a computer, the board has Print and TV view links. The TV view has large text and updates each minute. Use a login with view access to Training only for a TV in the tack room. On the Log tab, Download CSV gives the rows the filters show.

The dashboard tells you when today's board is not started, when a lot from the last 14 days is not confirmed, and when a horse in work has had no work. Switch these off in Settings, under reminders, with Training.

Work types

A work type is a kind of work, for example Canter or Horse walker. Each one has a kind (ridden, not ridden or rest) and an effort (Easy, Steady or Fast). A rest has no effort.

  1. Select Training in the sidebar.
  2. Select the Set up tab.
  3. Select Add work type, or Edit next to a work type.

A work type that records use cannot be deleted. Select Archive: it leaves the lists, and old records keep its name. You need full access to Training.

Charges for training

The yard can charge owners for some sessions, for example "Schooling £25". This is off until someone sets a price.

  1. Select Training, then the Set up tab.
  2. Select Edit next to a work type and type a Price. You need full access to Charges.
  3. In Settings, open each rate type for a livery that includes exercise, for example ridden livery. Tick Includes exercise.

When a session of a priced work type is Done, the horse's owner gets one charge on the Charges page. There is no charge when the horse's rate on that date includes exercise. Staff who confirm lots do not see prices.

  • A price change does not change work that is already Done.
  • When a lot is reopened, or a record is no longer Done, its charge goes, if it is not on an invoice.
  • When a charge is on an invoice, the record cannot be changed or deleted. Cancel or credit the invoice first.
  • A charge that you delete on the Charges page does not come back.

Common problems

Why can I not select Done for tomorrow?
Work is Done only after it happens. Select Planned, then confirm it on the day.
Why do I not see Training in the sidebar?
Your role needs access to Training. Ask an administrator to change it in Settings, Users & Roles.
Why is a horse in its lot but not on today's board?
Only horses In work, on Light work or in Pre-training go on the board. Or the horse joined the lot after the board started: the lot shows it with an Add button.
Why can I not select Mark lot done?
The board is for a date after today. Work is Done only after it happens.
Why can I not tick a horse when I add horses to a lot?
It is already in another lot. Its lot's name shows next to it. On the Lots tab, use Move to.
Why can I not archive a lot?
It still has horses. Move or remove them first.
I recorded the wrong horse. What do I do?
Open the record and select Edit to correct it. Select Delete only for a record made by mistake.
