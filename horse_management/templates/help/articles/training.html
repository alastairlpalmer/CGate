Training holds what each horse did and what is planned for it. Each record is one piece of work by one horse on one date: for example a canter, a session on the horse walker or a rest day.

Record training for one horse

  1. Open the horse's page.
  2. In the Record card, select Training.
  3. Select the work and the date.
  4. Select the status: Done, Planned or Did not work.
  5. Select Save.

A record for today or an earlier date starts as Done. A record for a later date starts as Planned. Work cannot be Done on a date after today.

If the horse did not work, select Did not work and give the reason, for example Lame or sore. If you leave Minutes empty, Cgate uses the usual minutes of the work.

You can also select Training activity in the Add menu.

Record training for many horses

  1. Select Horses in the sidebar.
  2. Tick the box next to each horse.
  3. In the bar at the bottom of the screen, open Choose action....
  4. Select Record Training.
  5. Select Apply to Selected.
  6. Complete the form, then select Record for and the number of horses.

Cgate makes one record for each horse. A horse that has left the yard is not recorded, and the message names it.

Confirm planned work

Planned work counts as work only when someone confirms it. Planned work from a past day shows as Not confirmed.

  1. Select Training in the sidebar. The Log tab opens.
  2. Select Show them in the yellow box, or set Status to Not confirmed.
  3. Tick the rows.
  4. Select Mark done. Or choose a reason and select Did not work.

On a horse's page, the Training card has the same two buttons on each planned row.

Work types

A work type is a kind of work, for example Canter or Horse walker. Each one has a kind (ridden, not ridden or rest) and an effort (Easy, Steady or Fast). A rest has no effort.

  1. Select Training in the sidebar.
  2. Select the Set up tab.
  3. Select Add work type, or Edit next to a work type.

A work type that records use cannot be deleted. Select Archive: it leaves the lists, and old records keep its name. You need full access to Training.

Common problems

Why can I not select Done for tomorrow?
Work is Done only after it happens. Select Planned, then confirm it on the day.
Why do I not see Training in the sidebar?
Your role needs access to Training. Ask an administrator to change it in Settings, Users & Roles.
I recorded the wrong horse. What do I do?
Open the record and select Edit to correct it. Select Delete only for a record made by mistake.
