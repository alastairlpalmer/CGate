The Breeding area follows your mares from covering to foaling. Use it to record coverings, scans and foalings, and to follow the EHV vaccinations and the foals.

See your breeding records

  1. Open Breeding in the sidebar. On a phone, select More, then Breeding.
  2. Read the summary at the top, for example In foal and Foals due in 30 days.
  3. To show less, use the Mare, Status and Season filters.
  4. Select Foaling calendar to see all pregnancies of a year on one timeline.
  5. Select Season results to see the conception rate and the live foals of each stallion.

Record a covering

  1. On the Breeding Records page, select Record Covering.
  2. Select the Mare.
  3. Type the Stallion name and the Date covered.
  4. Select Save.

Cgate calculates the foal due date as 340 days after the latest covering. If the mare is covered again in the same cycle, select Record covering on her record. Then select Add Covering. You need full access to Breeding to record a covering.

Record a scan

  1. Find the record of the mare and select Scan.
  2. Select the type of Scan, for example 14-day scan or Heartbeat scan.
  3. Set the Scan date.
  4. Select the Result: In foal, Not in foal, Twins or Inconclusive.
  5. Select Record Scan.

A result of In foal sets the record to Confirmed In-Foal. A result of Not in foal closes the record.

Follow the EHV vaccinations

A mare in foal needs an EHV dose at months 5, 7 and 9 after the covering. The Next EHV column on the Breeding Records page shows the next dose. The page of the mare shows all three dates in EHV Vaccination Schedule.

  1. Open the page of the mare.
  2. Select Record, then select Vaccination.
  3. Select a Vaccination type that has "EHV" in its name.
  4. Set the date and select Save.

You need full access to Health to record a vaccination.

Record a foaling

  1. Find the record of the mare and select Record foaling.
  2. Set the Date of birth and select the Sex.
  3. Select Create a new record and type the Foal name. Or select Link an existing horse.
  4. If necessary, select new rates in Yard board & billing.
  5. Select Record Foaling.

The new foal gets the mare as its dam, the stallion as its sire, and the owners of the mare.

Wean a foal

  1. Open the page of the mare. Find the foal in the Foals table.
  2. Select Wean.
  3. Set the Weaning date.
  4. Select Stays where it is or Move to another location.
  5. Select Record Weaning.

To change the name, sex or colour of a foal, select Edit foal details in the Foals table.

Common problems

My mare is not in the Mare list. Why?
The list shows only active horses with the sex Mare. Open the horse, select Edit and set the Sex to Mare.
Cgate says that the mare already has an open breeding record. What do I do?
Do not make a new record. Select Record covering on her open record to add the new covering.
I gave the EHV dose, but it still shows as due. Why?
The vaccination type must have "EHV" in its name. The date must be between three weeks before and one week after the due date.
The foal due date is wrong. How do I change it?
Select Edit on the breeding record. Type the correct date in Foal due and select Save changes.
