The Locations area shows the places where your horses live, grouped by site: grazing, barns and stables. Use it to see which horses are where, to rest a location and to check capacity.

See your locations

  1. Open Locations in the sidebar.
  2. Select Map to see the locations on a map. Select Cards to see a card for each location.
  3. On the map, select a site in Sites to see the locations of that site.
  4. In Cards, select the name of a location to open its page.

The map uses colours for Rest & rotation: Rested a fortnight or more, Still recovering, and In use or over. To draw the location boundaries from a Land App file, select Import field map.

Add a location

  1. Select the + button at the top right of the page.
  2. Select Add location.
  3. Type the Name, for example "Front Paddock".
  4. Select the Site. To make a new site, select "Add a new site…" and type its name.
  5. Select the Usage. If necessary, type the Capacity.
  6. In Where is it?, paste coordinates or a Google Maps link, or drop the pin on the map.
  7. Select Save.

You need full access to Locations to add or change a location.

Put horses into a location

  1. Open the page of the location.
  2. Select Log Arrival, then select Existing Horse.
  3. Select the horses. The list shows only horses that have no current placement.
  4. Select the Owner, the Rate Type and the Arrival Date.
  5. Select Log Arrival.

For a horse that is not in Cgate yet, select Log Arrival, then New Horse.

Move the horses of a location to a different location

  1. Select Locations, then select the location. On its own page, the button is at the top.
  2. Select Move horses. Cgate shows each horse that lives in the location, with a tick.
  3. Remove the tick from each horse that stays.
  4. In Move to, select the new location. Each location shows how full it is. If your site has a map, the nearest ground that is empty and rested shows as buttons.
  5. For the Move date, select Today or Pick a date. The date cannot be after today.
  6. Select Move … horses.

Each horse keeps its owner, its rate and its expected departure date. To give all the horses a different rate, select More options, then select a New rate.

The message that says the horses moved has an Undo button. If you sent the horses to the wrong location, select Undo. Cgate puts each horse back in the location that it came from. Then move the horses again.

A location with no horses shows Log arrival in place of Move horses. To bring horses into an empty location, open the location that the horses are in, and move them from there.

Check the capacity of a location

  1. Open the page of the location.
  2. Read Current Horses, Capacity and Available at the top of the page.
  3. If the capacity shows Not set, select Edit. Type the Capacity and select Save changes.

On the map, a location with more horses than its capacity shows as Over capacity.

Rest a location or change its land use

  1. Open the page of the location.
  2. Select the Usage tab.
  3. In Change usage, select the new Usage, for example Rested or Hay.
  4. Set the Effective date. A date in the past backdates the change.
  5. Select Save.

An empty location rests automatically. When a horse arrives, the location shows as in use again.

Add a barn and its stables

This item shows only when barns are turned on for your yard.

  1. Select the + button, then select Add barn.
  2. Type the Name and select the Site.
  3. Type the Number of stables and the First stable number.
  4. Select Save.
  5. To put a horse in a stable, open the barn page and select the stable. Then select Put here.

Common problems

How do I remove a location that we do not use now?
On a computer, open the location and select Edit, then Open the full form. Select Archive Location. Cgate keeps its history and hides it from lists and pickers.
I cannot archive a location. Why?
Horses are still on the location. Move the horses to a different location first.
My location is not on the map. Why?
The location has no boundary yet. Select Import field map and upload the GeoJSON file from Land App. Then match each shape to a location.
A horse in Move horses has no tick, and I cannot add one. Why?
The horse arrived in this location today. A stay cannot start and end on the same day. Move the horse tomorrow, or open the page of the horse and change the dates of its stay.
I moved a group of horses to the wrong location. What do I do?
Select Undo on the message that says the horses moved. Cgate puts each horse back, and its history shows no move. The message stays until you close it or open a different page. If the message is not there, open the page of each horse and change its stay.
I selected Undo, and one horse did not go back. Why?
Something changed for that horse after the move. For example, the horse left the yard, or its new stay is on an invoice. Cgate tells you the name of the horse and the reason. To change its stay, open the page of the horse.
Cgate says that the new location is over its limit. Did the move work?
Yes. Cgate moves the horses and tells you, so that you can check the number.
A location shows as rested, but I did not change it. Why?
The last horse left the location. An empty location rests automatically.
