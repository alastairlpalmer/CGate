This guide is for administrators. It tells you how to add users, give each user a role, and control what each role can see and change.

You need full access to Users & Roles to do the tasks in this guide.

Invite a user

  1. Select Settings in the sidebar.
  2. Select Users & Roles.
  3. In Users, select Add User.
  4. Enter the First Name, Last Name and Email.
  5. Select the Role.
  6. Do not enter a password.
  7. Select Add User.

Cgate emails an invitation to the new user. The user then chooses their own password. If the link expires or the email is lost, edit the user and select Send Invitation Again.

Make or change a role

  1. In Users & Roles, find Roles.
  2. Select New Role, or select Edit next to a role.
  3. Enter the Role Name and a Description.
  4. In Feature Access, select one access level for each area.
  5. Select Create Role or Save Role.
  • Hidden: the area is not in the sidebar. The user cannot open it.
  • View only: the user can see the area, but cannot add or change records.
  • Full access: the user can see, add and change records.

Some areas, for example Finances overview, have only Hidden and Full access. The Administrator role always has full access to all areas. You cannot change it.

To delete a role, edit it and select Delete Role. If users have this role, select a different role for them first.

Change the role of a user

  1. In Users, select Edit next to the user.
  2. Select a different Role.
  3. Select Save Changes.

You cannot remove your own access to Users & Roles. Ask a different administrator to do it.

Deactivate a user

  1. In Users, select Edit next to the user.
  2. In Account Status, select Deactivate.
  3. Confirm the action.

A deactivated user cannot sign in. Cgate keeps their history. To let the user sign in again, select Reactivate. To end all the sessions of a user immediately, select Sign Out Everywhere.

Two-step sign-in for administrators

A user with the Administrator role must use two-step sign-in. Cgate asks the user to set it up at their next sign-in.

In Sign-In Security on the user's page, an administrator can do these tasks for a different user:

  • Select Turn Off when the user lost their phone. Do this only when you are sure who is asking.
  • Select Excuse when the user cannot use an authenticator app. Then a password alone protects their account.

Read the audit log

  1. In Users & Roles, find System.
  2. Next to Audit Log, select Open.

The audit log shows who did what, and when. The newest change is first. Only administrators can see it.

Common problems

A user sees "Your role doesn't include access to that area". What do I do?
Edit the role of the user. Set that area to View only or Full access.
A user is locked out after too many wrong passwords. What do I do?
Edit the user and select Unlock. The lock also stops after a short time.
Why is Users & Roles not in my Settings?
Your role does not have full access to Users & Roles. Ask an administrator.
