The Farrier page holds all farrier work. It shows the farrier records, the visits from the farrier's phone, and the list of horses for the next visit.

Find your way on the Farrier page

  1. Select Farrier in the sidebar.
  2. Select a tab: Records, Visits from the farrier's phone or Farrier's list.

On a phone, the tabs are Records, Visits and List. The Due box at the top of Records shows the horses that are due. A horse in red is overdue.

Record a farrier visit for one horse

  1. On the Records tab, select Add a record.
  2. Select the horse and the work done.
  3. Enter the date of the visit.
  4. Select Add Visit.

If you do not enter the next due date, Cgate sets it to 6 weeks after the visit. If you enter a cost, Cgate adds a charge to the owner's next invoice.

You need full access to Health to add a record.

Record a farrier visit for several horses

  1. Select Horses in the sidebar.
  2. Tick the box next to each horse.
  3. In the bar at the bottom of the screen, open Choose action....
  4. Select Record Farrier Visit.
  5. Select Apply to Selected.
  6. Complete the form, then select Record for and the number of horses.

Find the horses that are due

  1. On the Records tab, select Filters.
  2. In Status, select Due Soon or Overdue.

Due Soon means that the next due date is in the next 14 days. Overdue means that the next due date is in the past.

Make a list for the farrier

  1. Select the Farrier's list tab.
  2. Enter the Visit date.
  3. Select the Horse and the Work wanted.
  4. Select Add to the list.

On that day, the farrier sees these horses at the top of their own page.

Give the farrier their own page

The farrier can record the work on a phone. You need full access to Users & Roles and to Business settings to set this up.

  1. In Settings, select Users & Roles.
  2. Select Add User and give the user the role Farrier.
  3. In Settings, select Yard setup, then Service providers.
  4. Select Edit next to the farrier.
  5. In Farrier page login, select the new user, then save.
  6. To give the farrier the page address, select Print QR code on the Farrier page.

Anyone with the QR code can sign in as one of your farriers. Keep it on the yard. If a photo of the code got out, open Print QR code and select Make a new QR code. The old code stops working, and each farrier is signed out.

The farrier records the work for each horse, then selects Finish visit. The visit then shows on the Visits from the farrier's phone tab. Open the visit and select Mark as checked. After this, the farrier cannot change the visit.

To pay the farrier for a month, open Monthly statements and select Record payment to farrier. You need full access to Costs.

Common problems

The farrier sees "Your login is not linked to a farrier yet". What do I do?
Open the farrier in Service providers. Select the farrier's user in Farrier page login, then save.
I opened the farrier's page and see "You are signed in as staff". Why?
That page is only for a farrier login. Use the Farrier page in the sidebar.
Why can I not see Print QR code?
Your role needs full access to Business settings.
