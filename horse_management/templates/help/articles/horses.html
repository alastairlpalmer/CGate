The Horses area shows the horses on your yard. Use it to log arrivals, moves and departures, and to keep the records of each horse.

Find a horse

  1. Open Horses in the sidebar.
  2. In View, select All, Location or Owner to group the horses.
  3. Select Sort to change the order. In Show, select Active or Departed.
  4. Select Movements to see the log of arrivals, moves and departures.
  5. Select the name of a horse to open its page.

The Active list shows only the horses that have a current placement at a location.

Log the arrival of a new horse

  1. Select the + button at the top right of the page.
  2. Select Log arrival.
  3. Type the Name of the horse. Add the other horse details that you know.
  4. Select the Owner. This owner gets 100% ownership.
  5. Select the Location, the Rate Type and the Arrival Date.
  6. Select Create & Arrive.

If the horse is already in Cgate, open its page and select Log Arrival. You need full access to Horses to log an arrival.

Move a horse to a different location

  1. Open the page of the horse.
  2. Select Move.
  3. Select the New location.
  4. For the Move date, select Today or Pick a date.
  5. To change the owner or the rate, select More options. Then select a New owner or a New rate.
  6. Select Move Horse.

Log a departure

  1. Open the page of the horse.
  2. Select More, then select Depart….
  3. In Depart on, set the date that the horse leaves.
  4. Select Confirm.

If the date is in the future, the horse stays on the yard until that date. Log the departure again on the day that the horse leaves.

Keep the passport, microchip, documents and photos

  1. Open the page of the horse and select Edit.
  2. Type the Passport number and the Microchip number. Then select Save Changes.
  3. To add a passport scan, select + Add on the Documents card.
  4. Select the type of document, for example Passport. Then choose the file and select Upload.
  5. To add photos, select + Add on the Photos card.
  6. Select what the photos show. Select Take photo or Choose from gallery, then save.

To show a photo next to the name of the horse, select Also use as profile picture before you save.

Set the owners of a horse

  1. Open the page of the horse.
  2. On the Ownership card, select Manage.
  3. For each owner, select the Owner and type the Share %.
  4. Select Primary for the owner who gets the livery invoice.
  5. Select Save Ownership.

The shares must total 100% or less. Livery and extra charges are split by these percentages.

Common problems

I added a horse, but it is not in the list. Why?
The horse has no current placement, so it shows under Departed. Open its page and select Log Arrival.
I cannot see the Move or Edit buttons. Why?
Your role gives you view-only access to Horses. Ask an administrator to give you full access.
I logged a departure, but the horse is still on the yard. Why?
You set a date in the future. Cgate keeps the horse in its location until that date.
How do I find a horse by its microchip or passport number?
Type the number in the search box. The search finds horses by name, microchip or passport number.
