The Horses area shows the horses on your yard. Use it to log arrivals, moves and departures, and to keep the records of each horse.

Find a horse

  1. Open Horses in the sidebar.
  2. In View, select All, Location or Owner to group the horses.
  3. Select Sort to change the order. In Show, select Active or Departed.
  4. Select Movements to see the log of arrivals, moves and departures.
  5. Select the name of a horse to open its page.

The Active list shows only the horses that have a current placement at a location.

Log the arrival of a new horse

  1. Select the + button at the top right of the page.
  2. Select Log arrival.
  3. Type the Name of the horse. Add the other horse details that you know.
  4. Select the Owner. This owner gets 100% ownership.
  5. Select the Location, the Rate Type and the Arrival Date.
  6. Select Create & Arrive.

If the horse is already in Cgate, open its page and select Log Arrival. You need full access to Horses to log an arrival.

Move a horse to a different location

  1. Open the page of the horse.
  2. Select Move.
  3. Select the New location.
  4. For the Move date, select Today or Pick a date.
  5. To change the owner or the rate, select More options. Then select a New owner or a New rate.
  6. Select Move Horse.

Log a departure

  1. Open the page of the horse.
  2. Select More, then select Depart….
  3. In Depart on, set the date that the horse leaves.
  4. Select Confirm.

If the date is in the future, the horse stays on the yard until that date. Log the departure again on the day that the horse leaves.

Keep the passport, microchip, documents and photos

  1. Open the page of the horse. On the Identity card, select Edit.
  2. Type the Microchip, the UELN and the Passport number. You can also scan the chip into the Microchip box. Then select Save Changes.
  3. If a number looks wrong, or another horse has the same number, a message tells you after the save. The save still happens.
  4. To add a passport scan, select + Add on the Documents card.
  5. Select the type of document, for example Passport. Then choose the file and select Upload.
  6. To add photos, select + Add on the Photos card.
  7. Select what the photos show. Select Take photo or Choose from gallery, then save.

To show a photo next to the name of the horse, select Also use as profile picture before you save.

Check the microchip and add other numbers

  1. On the Identity card, select Scan to check.
  2. Scan the chip. If the number matches the record, the horse gets the ID checked badge.
  3. If the number is different, scan again. If the record is wrong, select Save the scanned number. The old number stays on the card as an Old microchip.
  4. To add a stud-book number or a link to the horse on Weatherbys or Racing Post, select + Number or link.

A change to the microchip, UELN or passport number removes the ID checked badge, until someone scans the chip again.

Record the pedigree

  1. On the Pedigree card, select Edit.
  2. Type the Sire, the Dam and the Dam's sire. Pick a name from the list if it is there. You can add a suffix and a year, for example Copper Ridge (GB) 2004. Select More for the other grandparents.
  3. If the name is already on file, the form asks which horse you mean. Choose it, or choose New record for a different horse with the same name.
  4. Type Unknown for a parent that is not known.
  5. Select Save.

Each horse in a pedigree is one record that every horse shares. Type a stallion's parents once, and they show for all his foals. When you record a foaling, the foal gets the mare's and the stallion's records, so its grandparents show with no typing.

A grandparent belongs to the parent's own record. If you change the dam's sire, it changes for every foal of that dam. The form tells you how many horses that is.

Select a box in the tree to see that horse's own pedigree. A horse that appears twice is marked, for example 2×3: that is inbreeding, as on a sales catalogue page. Select Show 3 generations to see more.

Fill in many records

  1. On the Horses list, select Fill in records.
  2. The list shows each horse with a count, for example 6 of 9. The 9 details are the registered name, country, foaling date, microchip, UELN, passport number, sire, dam and dam's sire. Use Missing to show only the horses with no microchip, for example.
  3. Select a horse. Type what you have from the passport.
  4. Select Save and next. The next horse in the list opens.

After each save, the message has an Undo button. If someone else changed the horse while you had it open, the save stops and tells you who changed it.

To change many horses in a spreadsheet, select Download as CSV.

Correct a pedigree record

  1. In Fill in records, select Pedigree records.
  2. Tick Possible duplicates only to find two records for one horse, for example Moonlit Bay and Moonlight Bay.
  3. Select Compare and merge. You see both records and their pedigrees.
  4. If they are the same horse, choose Keep this one on the correct record, then select Merge.

After a merge, every foal and pedigree that used the other record uses the kept one. The message has an Undo button if you merged the wrong records.

Import horse records from a spreadsheet

  1. In Fill in records, select Import a file.
  2. Select Download the template. Fill it in with Excel, one horse on each line. Save it as CSV UTF-8.
  3. Select the file, then Read the file. Nothing changes yet.
  4. Check each line. The app finds the horse by microchip, then UELN, then registered name, country and year. A line with only a yard name that is already on the system shows Possible match: choose the horse, or tick Add as a new horse.
  5. Select Apply ticked changes.

A change is ticked only when the horse has no value now. A value that someone typed is never replaced unless you tick it. If a value changes while you review, Apply skips it and says so.

To use details already on the system, select Look for details. It reads the breeding notes (for example By Galileo out of Starlit Rose) and names such as Avicii (Karma Avicii), and shows what it found for you to review.

How the age is worked out

Every horse is a year older on 1 January. A horse foaled in the southern hemisphere (for example with the suffix ARG or AUS) is a year older on 1 August. If you do not know the foaling date, type only the year. If the year is a guess, tick The year is a guess: the page then shows foaled c. 2011.

Set the owners of a horse

  1. Open the page of the horse.
  2. On the Ownership card, select Manage.
  3. For each owner, select the Owner and type the Share %.
  4. Select Primary for the owner who gets the livery invoice.
  5. Select Save Ownership.

The shares must total 100% or less. Livery and extra charges are split by these percentages.

Common problems

I added a horse, but it is not in the list. Why?
The horse has no current placement, so it shows under Departed. Open its page and select Log Arrival.
I cannot see the Move or Edit buttons. Why?
Your role gives you view-only access to Horses. Ask an administrator to give you full access.
I logged a departure, but the horse is still on the yard. Why?
You set a date in the future. Cgate keeps the horse in its location until that date.
How do I find a horse by its microchip or passport number?
Type the number in the search box. The search finds horses by name, registered name, microchip, UELN or passport number.
